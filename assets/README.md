# Mouse artwork and feedback graphics

`mouse.gif` is an unchanged copy of `../../cpp-code/maus.h5.gif`, retained as the
original reference. Its provenance and redistribution rights have not been
independently established.

`mouse-transparent.png` is the transparent derivative generated with Imagegen
on 2026-11-13 from that original mouse. The model recreated the illustration
while removing the background; it is not a pixel-identical extraction. This
asset is used both during trials and in block summaries. It has an RGBA alpha
channel and is drawn normally over the circle, without color blending.

The mouse is drawn first, then the large `cheese.svg` overlay for an incorrect
response, or cage bars for a correct response. The cheese overlay covers the
body while keeping the head visible. It replaces the small system emoji.

`cage.svg` and `cheese.svg` are code-authored vector illustrations, also used in
the block summary. The original files remain unchanged.
